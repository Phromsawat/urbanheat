Backend Spatial Join (Python Code)

สคริปต์ประมวลผลควบรวมพิกัดดิบจากดาวเทียม 4,800 จุด (Shapefile) ให้เฉลี่ยสะสมแยกตามขอบเขต 11 อำเภอชลบุรี

spatial_join_districts.py (ส่วนย่อ)
import geopandas as gpd import pandas as pd # 1. โหลดข้อมูลแผนที่ขอบเขตอำเภอ และพิกัดตรวจวัดความร้อน/แก๊ส grid = gpd.read_file('chonburi_gas_lst.geojson').to_crs(epsg=4326) districts = gpd.read_file('chonburi_districts.geojson').to_crs(epsg=4326) # 2. คัดกรองรูปหลายเหลี่ยมหลัก (ตัดพื้นที่ผืนน้ำทะเลที่ทับซ้อนทิ้ง) districts['geometry'] = districts['geometry'].apply(keep_largest_polygon) # 3. รันการ Spatial Join ตรวจสอบว่าพิกัดจุดดิบอยู่ในอำเภอใด joined = gpd.sjoin(grid, districts[['name', 'geometry']], how='left', predicate='within') # 4. คำนวณหาค่าเฉลี่ยสถิติเชิงพื้นที่ในแต่ละอำเภอแยกตามรายปี (2018-2026) data_cols = [c for c in joined.columns if 'LST_' in c or 'CH4_' in c] district_agg = joined.groupby('name')[data_cols].mean().reset_index() # 5. เชื่อมรวมข้อมูลสถิติและค่าทำนายปี 2027 กลับเข้าขอบเขตอำเภอ districts_out = districts.merge(district_agg, on='name', how='left') districts_out.to_file('chonburi_districts_with_data.geojson', driver='GeoJSON')
⚡ ประสิทธิภาพสถาปัตยกรรม Flat-file

• แก้คอขวด CPU หน้าบ้าน: การโหลดจุดกริดดาวเทียม 4,800 จุดเพื่อเรนเดอร์ในเบราว์เซอร์จะทำให้หน้าเว็บกระตุกและช้า เราจึงย้ายมาประมวลผลหลังบ้านแบบ Static ล่วงหน้า

• Spatial Average: โค้ดใช้ gpd.sjoin หาค่าเฉลี่ยเชิงเรขาคณิต (Spatial Mean) ของอุณหภูมิ LST และก๊าซ GHG รายปีเข้าสู่รูปทรงอำเภอ

• ฝังข้อมูลเป็นก้อนเดียว (GeoJSON Properties): ผลลัพธ์ถูกจัดเก็บลงเป็น Properties ในไฟล์ GeoJSON ขนาดเล็ก 776 KB แทนฐานข้อมูล SQL หน้าบ้านจึงดึงข้อมูลมาวาดสีแผนที่ได้ทันที

Frontend Map View Component (Leaflet JS)

การโหลดแผนที่โพลีกอนระบายเฉดสีแบบ Choropleth และการเชื่อมโยงปฏิสัมพันธ์ของเมาส์ผู้ใช้เพื่อแสดง Popup

components/MapView.js (ส่วนย่อ)
import L from 'leaflet'; import { getLstColor } from '../data/sampleData'; export default function MapView({ yearIndex, onZoneSelect, tempDrop = 0 }) { const mapRef = useRef(null); useEffect(() => { // 1. Initialize Leaflet Map Object const map = L.map(mapRef.current, { center: [13.3, 101.1], zoom: 9 }); // 2. โหลดไฟล์ GeoJSON สะสมเฉลี่ยจาก Public Assets โฟลเดอร์ fetch('/chonburi_districts_with_data.geojson') .then(res => res.json()) .then(data => { // 3. เรนเดอร์โพลีกอนรายอำเภอลงบนแผนที่แบบ Vector Layer L.geoJSON(data, { style: feature => ({ // นำอุณหภูมิ LST หักลบค่าจำลองระดับความเย็น (tempDrop) ก่อนแสดงผลสี fillColor: getLstColor(feature.properties[`LST_2026`] - tempDrop), weight: 1.5, color: 'rgba(255,255,255,0.3)', fillOpacity: 0.7 }), onEachFeature: (f, layer) => { layer.bindTooltip(buildPopupHTML(f.properties)); layer.on('click', () => onZoneSelect(f.properties)); } }).addTo(map); }); }, [tempDrop]); return <div ref={mapRef} id="map" />; }
🗺️ จุดเด่นทางเทคนิคฝั่งหน้าบ้าน

• Client-side Rendering (CSR): ใช้ Next.js dynamic import ป้องกันปัญหา SSR ของ Leaflet ที่พึ่งพาอ็อบเจกต์ window ของบราวเซอร์

• Choropleth Rendering: ฟังก์ชัน getLstColor จะสแกนหาค่าอุณหภูมิของแต่ละโพลีกอนอำเภอใน GeoJSON เพื่อระบายเฉดสีแดงส้ม (ร้อนจัด) และสีสว่าง (เย็น)

• Dynamic Style Update: แผนที่จะตรวจจับการเปลี่ยนค่า tempDrop เพื่อเปลี่ยนสีโพลีกอนของจริงโดยไม่ต้องวาดแผนที่ใหม่ทั้งหมด ทำให้การเปลี่ยนสีลื่นไหล

State & Interactive Simulation Component

ระบบจัดการสถานะตัวแปร Slider และสมการจำลองอุณหภูมิที่จะลดลงจากการหักล้างปริมาณคาร์บอนและป่าไม้แบบเรียลไทม์

components/Dashboard.js (ส่วนย่อ)
import { useState, useMemo } from 'react'; import MapView from './MapView'; export default function Dashboard() { // 1. State ของสไลเดอร์ลดก๊าซ CO (%) และเพิ่มป่าไม้ (%) const [simCo2, setSimCo2] = useState(0); const [simGreen, setSimGreen] = useState(0); // 2. สมการประเมินความร้อนผิวพื้นที่หักล้างลงเชิงคณิตศาสตร์ (Simulation Model) // ลด CO 1% = LST ลดลง 0.03°C | เพิ่มพื้นที่สีเขียว 1% = LST ลดลง 0.05°C const tempDrop = useMemo(() => { return (simCo2 * 0.03 + simGreen * 0.05).toFixed(2); }, [simCo2, simGreen]); return ( <div className="dashboard-layout"> <aside className="sidebar"> <h3>Green Policy Simulation</h3> <label>ลดระดับ CO: {simCo2}%</label> <input type="range" min="0" max="50" onChange={e => setSimCo2(Number(e.target.value))} /> <label>เพิ่มระดับสีเขียว: {simGreen}%</label> <input type="range" min="0" max="50" onChange={e => setSimGreen(Number(e.target.value))} /> <div className="result">อุณหภูมิลดลงจำลอง: -{tempDrop} °C</div> </aside> <main className="map-container"> <MapView tempDrop={parseFloat(tempDrop)} /> </main> </div> ); }
⚛️ สถาปัตยกรรม React State & UI Flow

• สมการตอบสนองระดับมิลลิวินาที: การประมวลผล useMemo จะเกิดขึ้นเฉพาะเวลาที่ค่าสไลเดอร์มีการเปลี่ยนแปลง เพื่อประหยัด CPU ในการประเมินผลเชิงเลขคณิต

• Unidirectional Data Flow: ข้อมูลไหลในทิศทางเดียวจาก Dashboard.js (สไลเดอร์) ผ่าน Props tempDrop ไปยัง MapView.js เพื่อปรับเปลี่ยนการระบายเฉดสีโพลีกอนอำเภอต่างๆ

• การจำลอง 100% Client-side: ลดการส่งคำร้อง HTTP ไปที่ Vercel ทุกครั้งที่เลื่อนแถบจำลอง ทำให้ผู้ใช้งานสามารถลากสไลเดอร์และเห็นการอัปเดตของแผนที่ได้ทันทีโดยไม่มีการรอโหลดหน้าเว็บใหม่
