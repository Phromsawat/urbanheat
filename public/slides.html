04 — ระบบหลังบ้าน

ขั้นตอนที่ 1: แปลง Shapefile → GeoJSON

สคริปต์ convert_shp.py อ่านไฟล์ Shapefile ดิบจาก GIS แล้วแปลงค่าพิกัด, ปัดทศนิยม, เปลี่ยน NaN → null ตามมาตรฐาน JSON

  • อ่านข้อมูลจุดพิกัดกริดดาวเทียม 4,800 จุดทั่วจังหวัดชลบุรี
  • ปัดตำแหน่งพิกัดทศนิยม 5 ตำแหน่ง (ความแม่นยำ ±1.1m) เพื่อลดขนาดไฟล์
  • แปลงค่าผิดปกติ NaN/Infinity → null ป้องกัน JSON parse error
  • ส่งออก GeoJSON แบบ compact (ไม่มีช่องว่าง) เพื่อความเร็วในการโหลด

05 — ระบบหลังบ้าน

ขั้นตอนที่ 2: Spatial Join รวมข้อมูลรายอำเภอ

สคริปต์ spatial_join_districts.py เฉลี่ยค่าจุดกริด 4,800 จุดลงในเขตปกครอง 11 อำเภอ ด้วยวิธี Point-in-Polygon

  • โหลดขอบเขตอำเภอ 11 แห่งจาก OpenStreetMap
  • ตัดพื้นที่ผืนน้ำทะเล (Sea Clipping) — เก็บเฉพาะแผ่นดินใหญ่
  • ทำ Spatial Join: วิเคราะห์ว่าจุดใดอยู่ในเขตอำเภอใด
  • คำนวณค่าเฉลี่ย (Mean Aggregation) ต่อตัวแปรต่อปี
  • ฝังค่าสถิติลงใน Properties ของโพลีกอนอำเภอ

import geopandas as gpd # 1. Load grid points & district polygons grid = gpd.read_file('chonburi_gas_lst.geojson') districts = gpd.read_file('chonburi_districts.geojson') # 2. Clip sea areas (keep largest polygon) def keep_largest_polygon(geom): if geom.geom_type == 'MultiPolygon': return max(geom.geoms, key=lambda p: p.area) return geom # 3. Point-in-Polygon Spatial Join joined = gpd.sjoin(grid, districts, how='left', predicate='within') # 4. Aggregate Mean per District district_agg = joined.groupby('name')[data_cols].mean() # 5. Merge back into polygons result = districts.merge(district_agg, on='name') # 6. Export final GeoJSON # → chonburi_districts_with_data.geojson

🎛️ ระบบจำลอง (Simulation)

ผู้ใช้สามารถเลื่อน Slider เพื่อจำลองผลกระทบจาก:
• ลดก๊าซ CO (0–50%)
• เพิ่มพื้นที่สีเขียว (0–50%)

ระบบจะคำนวณอุณหภูมิที่ลดลงแบบ Real-time ทั้งบนกราฟและสีบนแผนที่

📐 สมการจำลอง

ΔTemp = CO_reduction × 0.03 + Green_area × 0.05

ทุกการลด CO 1% → LST ลด 0.03°C
ทุกพื้นที่สีเขียวเพิ่ม 1% → LST ลด 0.05°C

Dashboard.js
const [simCo, setSimCo] = useState(0); const [simGreen, setSimGreen] = useState(0); // คำนวณอุณหภูมิที่ลดลง (Real-time) const tempDrop = useMemo(() => (simCo * 0.03 + simGreen * 0.05) .toFixed(1), [simCo, simGreen] ); // ส่ง tempDrop ไปให้ MapView // → สีบนแผนที่เปลี่ยนทันที <MapView yearIndex={yearIndex} tempDrop={parseFloat(tempDrop)} /> // แสดงผลลัพธ์ Simulation <div className="sim-result"> อุณหภูมิลดลง: {tempDrop} °C </div>
